
# amltools

<!-- badges: start -->
<!-- badges: end -->

The goal of amltools is to automate project setup tasks for the Azure Machine Learning Studio platform that are otherwise performed manually.

## Installation

You can install the development version of amltools from [GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pkg_install("jeffery-leirness/amltools")
```
